Este app é um teste de implementação de uso do componente `axShockwaveFlash` para a execução de arquivos **SWF** do **Adobe Flash Player**. 

O diferencial dessa aplicação é a possibilidade de jogar jogos de flash antigos de forma 100% offline, minimizando completamente a exposição à anúncios, malwares e outras vulnerabilidades do **Adobe Flash Player**.

## Por que não o Ruffle?

O **Ruffle** é uma ótima iniciativa para substituir o **Adobe Flash Player**, porém alguns jogos elaborados especificamente para o **Adobe Flash Player** perdem qualidade e desempenho considerável no **Ruffle**. 

## É perigoso instalar o Adobe Flash Player? 

Os riscos dele estão diretamente ligados à adulteração dos arquivos SWF para execução de código arbitrário e roubo de dados! É mais seguro executar esse projeto em uma máquina virtual.

> Aviso: Os arquivos SWFs aqui foram coletados do **WayBack Machine**!
